UroFlow Diary

สมุดบันทึกอาการปัสสาวะและประวัติยา สำหรับนำข้อมูลไปปรึกษาแพทย์

รุ่นต้นแบบสำหรับทดสอบเท่านั้น — ข้อมูลเก็บในเบราว์เซอร์ของอุปกรณ์นี้ ไม่ส่งไปยังเซิร์ฟเวอร์ แต่ GitHub Pages เป็นเว็บไซต์สาธารณะ และเบราว์เซอร์ไม่ได้เข้ารหัสข้อมูลแอปให้อัตโนมัติ โปรดใช้ข้อมูลสมมติในการทดลองเท่านั้น ห้ามใช้ข้อมูลสุขภาพจริงจนกว่าจะมีการตรวจสอบความปลอดภัยและการกู้คืนข้อมูล

รายงานสำหรับแพทย์

เลือกช่วงวันที่เพื่อสร้างรายงานอาการและประวัติยา แล้วเลือก “บันทึกเป็น PDF” ในหน้าต่างพิมพ์

ข้อจำกัดการเก็บข้อมูล

  • ข้อมูลอยู่ในเบราว์เซอร์และอุปกรณ์ที่ใช้งาน หากล้างข้อมูลเว็บไซต์ เปลี่ยนเบราว์เซอร์ หรืออุปกรณ์ ข้อมูลอาจหายหรือไม่ปรากฏ
  • ไฟล์ JSON สำรองมีข้อมูลทั้งหมดและไม่ได้เข้ารหัส ควรเก็บในตำแหน่งปลอดภัย
  • การลบข้อมูลจากหน้าเว็บไม่รับประกันว่าข้อมูลจะถูกลบจากสำเนาสำรองหรือระบบสำรองข้อมูลของอุปกรณ์
  • ยังไม่มีการล็อกแอปที่ปลอดภัยหรือการเข้ารหัสฐานข้อมูลในรุ่น HTML นี้
คำเตือนทางการแพทย์: แอปนี้ไม่วินิจฉัยโรค ไม่ใช่ผลตรวจ Uroflowmetry และไม่แนะนำให้หยุดหรือปรับยาเอง หากปัสสาวะไม่ออกเฉียบพลัน ให้ไปห้องฉุกเฉิน หากมีเลือดปนในปัสสาวะหรืออาการรุนแรง ควรรับการประเมินจากบุคลากรทางการแพทย์
