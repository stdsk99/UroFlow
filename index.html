สมุดบันทึกอาการปัสสาวะและประวัติยา สำหรับนำข้อมูลไปปรึกษาแพทย์

ต้นแบบสำหรับทดสอบ — ข้อมูลจัดเก็บในเบราว์เซอร์เครื่องนี้ ไม่มีระบบคลาวด์ ข้อมูลที่บันทึกในรุ่นนี้เข้ารหัสในพื้นที่จัดเก็บด้วย Web Crypto หลังตั้งค่า PIN และรหัสกู้คืน แต่ไฟล์ส่งออก/รายงานเป็นไฟล์ที่อ่านได้ ต้องเก็บอย่างปลอดภัย โปรดทดสอบด้วยข้อมูลสมมติเท่านั้นก่อนผ่านการตรวจสอบความปลอดภัยอย่างเป็นทางการ

ข้อจำกัด

  • ข้อมูลจริงในต้นแบบนี้จัดเก็บเป็นข้อมูลเข้ารหัสใน localStorage โดยใช้ Web Crypto; อย่างไรก็ตามความปลอดภัยขึ้นกับอุปกรณ์ เบราว์เซอร์ และการปกป้อง PIN/รหัสกู้คืน
  • ไฟล์สำรองที่ดาวน์โหลดไม่ได้เข้ารหัสโดยอัตโนมัติ
  • การแจ้งเตือนเบราว์เซอร์เมื่อปิดหน้าเว็บไม่รับประกันว่าจะทำงาน จึงยังไม่เปิดระบบแจ้งเตือนเบื้องหลัง
  • ต้นแบบนี้ยังไม่ผ่านการทดสอบความปลอดภัยหรือการรับรองเป็นเครื่องมือแพทย์
